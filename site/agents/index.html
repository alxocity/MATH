agents

Read the snapshot. Ask for unsigned transactions. A human signs them in their own wallet. No server, no key, no MCP.

files

  • /index.json — tokens, owners, values, RGB and TOON parts, word and face text. The site loads this file. script/snapshot.js rewrites it, and the weekly workflow commits that same file.
  • /plan.js — plan(wallet, target, snapshot).
  • /llms.txt — short pointer.
  • /agents/example.json — three worked plans on a tiny fixture.

snapshot

{
  block: number,
  owners: ["0x…"],
  math: [["id", ownerIndex]],
  rgb: [["id", ownerIndex, r, g, b]],
  toon: [["id", ownerIndex, word, face, rgb]],
  words: { "id": "text" },
  faces: { "id": "text" },
  wordOwners: [ownerIndex],
  faceOwners: [ownerIndex],
  blocked: ["0x…"],
  blockedDone: true
}

Ids are decimal strings. ownerIndex indexes owners, which are lowercase. A used channel is an r, g, or b on an RGB row. wordOwners[id] and faceOwners[id] are the holders. WORD and FACE ids run from 0. blocked lists holders that revert MATH's 2300-gas payout. blockedDone is true when that list was scanned.

plan

AGENT.plan(wallet, target, snapshot)

AGENT.plan(wallet, "3", snap)
AGENT.plan(wallet, { math: "3" }, snap)
AGENT.plan(wallet, { r: "1", g: "2", b: "4" }, snap)
AGENT.plan(wallet, { math: "1", word: "2", face: "3", rgb: "4" }, snap)

In the browser, load abi.js, planner.js, eth.js, then plan.js. AGENT is the global. The workshop page already loads them. In Node, from site/:

const AGENT = require('./plan')
const snap = JSON.parse(fs.readFileSync('./index.json', 'utf8'))
AGENT.plan(wallet, '3', snap)

The result is JSON. v is 1.

{
  ok, kind, target, block, wallet, exists,
  txs: [{ to, data, value }],
  royalty, shares: [{ id, holder, wei, owned }],
  owned, note
}

value is hex wei. MATH sends 0.002 ETH. RGB sends 0.03 ETH. TOON sends 0x0. royalty and each share's wei are decimal wei, the part holders receive, not gas. owned lists input ids this address already holds. A share's owned is null only when the WORD or FACE owner index is missing. shares.holder is the owner in the snapshot. The contract pays whoever holds the input at send time.

ok: false means the snapshot shows the call reverting (a channel already used, a TOON part already used, a missing MATH or RGB, a WORD or FACE the signer does not hold, or a MATH input held by an address in blocked). The transactions are still returned. exists: true means that target is already minted, so txs is empty. A TOON plan is ok: true when the signer holds the MATH, WORD, FACE, and RGB.

caveats

  • A human signs. plan does not.
  • TOON.add is free. It reverts unless the signer holds the MATH, WORD, FACE, and RGB.
  • MATH pays each input holder 0.001 ETH with a 2300-gas transfer. Some contract wallets cannot receive it. blocked lists them when blockedDone is true. A route that still names one comes back ok: false.
  • RGB pays 0.01 ETH to each MATH channel holder. Hold a channel, or mint it earlier in the same plan, and that share is 0.
  • You still pay gas. value is only the msg.value.
  • The file is current as of block. It lags mainnet until the next snapshot.
