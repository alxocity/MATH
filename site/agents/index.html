agents

Read the snapshot. Ask for unsigned transactions. A human signs them in their own wallet. No server, no key, no MCP.

files

  • /index.json — tokens, owners, values, RGB and TOON parts, word and face text. The site loads this file. script/snapshot.js rewrites it, and the weekly workflow commits that same file.
  • /plan.js — plan(wallet, target, snapshot).
  • /llms.txt — short pointer.
  • /agents/example.json — three worked plans on a tiny fixture.

snapshot

{
  block: number,
  owners: ["0x…"],
  math: [["id", ownerIndex]],
  rgb: [["id", ownerIndex, r, g, b]],
  toon: [["id", ownerIndex, word, face, rgb]],
  words: { "id": "text" },
  faces: { "id": "text" }
}

Ids are decimal strings. ownerIndex indexes owners, which are lowercase. A used channel is an r, g, or b on an RGB row. WORD and FACE owners are not in the file. The list of holders who revert MATH's payout is not in the file either.

plan

AGENT.plan(wallet, target, snapshot)

AGENT.plan(wallet, "3", snap)
AGENT.plan(wallet, { math: "3" }, snap)
AGENT.plan(wallet, { r: "1", g: "2", b: "4" }, snap)
AGENT.plan(wallet, { math: "1", word: "2", face: "3", rgb: "4" }, snap)

In the browser, load abi.js, planner.js, eth.js, then plan.js. AGENT is the global. The workshop page already loads them. In Node, from site/:

const AGENT = require('./plan')
const snap = JSON.parse(fs.readFileSync('./index.json', 'utf8'))
AGENT.plan(wallet, '3', snap)

The result is JSON. v is 1.

{
  ok, kind, target, block, wallet, exists,
  txs: [{ to, data, value }],
  royalty, shares: [{ id, holder, wei, owned }],
  owned, note
}

value is hex wei. MATH sends 0.002 ETH. RGB sends 0.03 ETH. TOON sends 0x0. royalty and each share's wei are decimal wei, the part holders receive, not gas. owned lists input ids this address already holds. A share's owned is null when the snapshot has no owner for it.

ok: false means the snapshot shows the call reverting (a channel already used, a TOON part already used, or a missing MATH or RGB). The transactions are still returned. exists: true means that target is already minted, so txs is empty.

caveats

  • A human signs. plan does not.
  • TOON.add is free. It reverts unless the signer holds the MATH, WORD, FACE, and RGB.
  • MATH pays each input holder 0.001 ETH with a 2300-gas transfer. Some contract wallets cannot receive it. This snapshot does not list those contracts, so a route can still name one.
  • RGB pays 0.01 ETH to each MATH channel holder. Hold a channel, or mint it earlier in the same plan, and that share is 0.
  • You still pay gas. value is only the msg.value.
  • The file is current as of block. It lags mainnet until the next snapshot.
